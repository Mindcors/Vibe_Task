Python Mini Course

Введение в Python

Python — простой и мощный язык. Пишем код в файлах .py или прямо в интерпретаторе. В этом мини‑курсе мы разберём основы и сразу будем писать и проверять код.

Как это работает

В этом файле встроен «песочница»: ты пишешь код в текстовом поле, нажимаешь «Запустить», и он выполняется в браузере (через Pyodide). Результат выводится ниже.

Типы данных и переменные

Основные типы: int, float, str, bool, list, dict. Переменные создаются присваиванием.

# Пример
age = 25
pi = 3.14
name = "Алиса"
is_ready = True
numbers = [1, 2, 3]
person = {"name": "Алиса", "age": 25}

Условия и циклы

Условные конструкции if/elif/else и циклы for, while помогают управлять ходом программы.

x = 10
if x > 5:
    print("Больше 5")
else:
    print("5 или меньше")

for i in range(3):
    print(i)

Задание 3: Чётное или нечётное

Функции

Функции позволяют переиспользовать код. Объявляются через def.

def greet(name):
    return f"Привет, {name}!"

print(greet("Мир"))

Практика: мини‑задача

Объединим всё: переменные, условия, циклы и функции. Напиши программу, которая:

  1. Определяет функцию check_age(age): если возраст >= 18 — «Доступ разрешён», иначе — «Доступ запрещён».
  2. Создаёт список возрастов: [15, 18, 20, 17].
  3. Проходит циклом по списку и для каждого возраста вызывает функцию, выводя результат.
